# Каталог и страницы бенчмарков BenchFactory

Ветка `codex/benchfactory-catalog` основана на проверенном лендинге `codex/benchfactory-landing` (`0b5e0ea`).

## Перенос

Каталог `/catalog`, набор `/benchmark/:id?type=suite` и тест `/benchmark/:id` используют оригинальные разметку, локальные SB Sans, SVG, стили и порядок CSS-переопределений HTML. Каталог содержит горизонтальные ленты наборов и отдельные тесты; drawer — поиск значений, дерево классификации, счётчики и снятие фильтров. Состав набора поддерживает desktop preview, клавиатуру и прямой мобильный переход. На странице теста сохранены паспорт, источники, описание оценки, baseline и все примеры, включая подвыборки.

Данные загружаются через существующие API и реальные UUID. Страницы каталога подгружаются полностью, а поиск и facet counts используют доступные серверные записи: поиск охватывает название, описание, метрику, домен и способности. Внутри дерева выбираются альтернативные parent/child значения; между группами применяется пересечение. URL `search`/`language` и переход от шара сохранены. JSON содержит фактический DTO и доступные примеры; полный внешний датасет в него не входит.

«Улучшить» / «Улучшить набор» остаются неактивными по решению продукта. Быстрый просмотр старого каталога заменён исходным HTML-сценарием: карточка открывает страницу теста, а desktop preview доступен в составе набора.

## Границы данных

В публичном DTO сложность — одно значение; HTML допускает несколько. Версия набора и заявленное дизайнером число тестов не представлены в API. Отсутствующие сведения не подставляются из демонстрационного JSON. Живые записи поэтому могут отличаться по текстам, числам и высоте от демо, сохраняя исходные правила отображения.

## Проверка

Для сравнения в реальном Chromium исходный `bf-data` преобразован только в browser test fixtures тех же API DTO. Эти фикстуры не входят в приложение. Отдельно проверяется настоящий dev API без подмены данных. Артефакты и pixel diff хранятся в игнорируемом `.local-reports/catalog/`.

Повторная матрица: каталог, drawer, состав и «О наборе», полный тест — 1440×1000 и 390×844. Геометрия, computed styles и текст: 0 расхождений во всех 10 сценариях. Drawer и страницы набора: 0 пиксельных различий; тест: 0 на desktop и 41 пиксель на mobile. Остаток каталога 9 451 / 13 793 760 desktop и 9 503 / 7 275 060 mobile связан с отсутствующим в API declared metadata и растеризацией. Контент приложения не подменяется встроенным demo JSON.

Тесты автора читаются отдельным авторизованным endpoint: ссылки «Ваши бенчмарки» сохраняют `submission=mine`, публичные запросы не выполняются. Гость перенаправляется на вход с сохранением назначения.

Живой dev API: 26/26 браузерных проверок успешны (62 набора, 268 тестов на момент проверки). Проверены все 11 taxonomy-параметров, drawer/focus/scroll, поиск и сброс, выбор теста, mobile, источники и оба JSON-export. Ошибок JS и неудачных API-запросов нет; «Улучшить» не меняет маршрут и не отправляет mutation. Независимое визуальное ревью: ship, материальных замечаний нет. Build/lint и полный набор из 67 файлов / 519 тестов прошли; после исправления own-submission counts повторены 40 тестов каталога, build/lint.

Уточнение методики: исходный visual report считает различием изменение больше 8 уровней RGB, отдельно проверены строгие PNG-сравнения без допуска. Состав и «О наборе» совпадают строго на desktop/mobile, полный тест — строго на desktop. Drawer: 1 550 пикселей desktop и 3 mobile отличаются максимум на 4 уровня RGB; mobile тест — 79 пикселей (41 при допуске 8). Эти остаточные различия не скрываются заявлением о побитовой идентичности всего приложения.

После независимого аудита 30 октября исправлены пересечение групп/конкретных способностей/тегов, поиск по обоим именам набора и модальности, сохранность escape-последовательностей в примерах и исходная SVG-иконка фильтров. Добавлены регрессионные тесты выдачи и facet counts. Живой Chromium подтвердил 6 результатов для сочетания Agentic & Tool-Mediated Reasoning + Planning, 129 по запросу «Банковская корзина» и полное совпадение DOM-текста примера USE с исходным DTO; вложенный JSON остаётся валидным.

Повторное сравнение каталога/drawer/набора/теста на 1440 и 390 px после исправлений: геометрия, стили и текст — без расхождений, горизонтального переполнения нет. Строгий PNG diff сохраняет небольшие различия растеризации и ранее описанные ограничения данных; побитовая идентичность всех экранов не заявляется.
